🗣 Ce que je comprends (phrases & commandes)

Ranger : « pour le projet X … », « côté Y, … » (sous-projet), # X / ## Y au clavier.

Fournisseurs : « chez Dupont », « le fournisseur Dupont », @Dupont · statuts : « devis reçu », « commandé », « livré », « contacté », « litige ».

Dates : demain, vendredi, semaine prochaine, dans 3 jours, 12/12, 5 mars. Priorité : urgent / critique, important. Effort : rapide.

🔗 Lier : « lie A à B », « relie A avec B », « lie-le à B » (dernier élément dicté), « A dépend de B », « A bloque B », « délie A et B ».

⚙︎ Modifier : « marque A comme fait », « A c'est fait », « mets A en urgent », « reporte A à lundi », « déplace A dans Projet », « supprime A ».

Avec une clé API Claude (⚙︎), l'IA comprend la parole libre bien mieux et crée aussi les liens évidents toute seule.

Raccourcis : N formulaire · D dictée · 1-4 vues · ⌘Z annuler
